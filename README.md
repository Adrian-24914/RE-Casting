# Resident Evil Casting

## Ejecutar

```powershell
cargo run --release
```

`assets/Background.mp3` es la canción usada por la opción **Taylor Swift**. La
aplicación no descarga música: el archivo debe permanecer en esa ruta.

## Controles

- Menú: `↑`/`↓` seleccionan uno de los dos niveles, `T` alterna entre música
  normal y Taylor Swift, `Enter` inicia y `Q` sale.
- Juego: `W`/`S` avanzan y retroceden; `A`/`D` o el movimiento horizontal del
  mouse rotan la cámara; `M` alterna entre la vista 3D y el mapa; `Esc` vuelve
  al menú.
- Victoria: `Enter` o `Esc` vuelven al menú.
